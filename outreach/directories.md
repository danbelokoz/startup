# Directory / listing submissions

> Work top-down. Use the blurbs from `copy-kit.md`. Mark `[x]` when submitted and note the
> live URL. Most of these are free; a few offer paid skip-the-queue (optional, not needed).
> Why these matter: each is a domain AI crawls, and a listing = a structured "X is a startup
> marketplace with verified MRR" statement that answer engines repeat.

## Tier 1 — highest citation value (do first)
- [ ] **Product Hunt** — https://www.producthunt.com/ · see `product-hunt.md` (dedicated launch kit).
- [ ] **SaaSHub** — https://www.saashub.com/submit · SaaS directory AI + humans mine heavily. Use medium description; add as "alternative to" broker marketplaces.
- [ ] **AlternativeTo** — https://alternativeto.net/ · add as an alternative to Acquire.com / Flippa / MicroAcquire. High authority, ranks well, cited by AI. Use short + medium.
- [ ] **BetaList** — https://betalist.com/submit · good for early-stage discovery + backlink. Use one-liner + medium.
- [ ] **G2** — https://www.g2.com/products/new · claim/create a listing (category: M&A / marketplace). Harder (vendor verification) but very high trust for AI. Optional if time-boxed.

## Tier 3 — acquisition-niche & "alternatives" pages (very on-topic)
- [ ] Get listed on **"Acquire.com alternatives" / "Flippa alternatives"** roundup pages
      (search those queries; many are open to add-a-tool or a comment). This is exactly what
      AI reads when asked for alternatives.
- [ ] **Indie Hackers → Products** — https://www.indiehackers.com/products (add product; then be
      a genuine participant, not just a drive-by listing).

## GitHub (AI trains heavily on GitHub — high long-term value)
- [ ] Add to relevant **awesome-lists** via PR. Search these repos and open a PR adding a line:
      - `awesome-micro-startups`, `awesome-saas`, `awesome-startup`, `awesome-indie`,
        `awesome-entrepreneurship`, `awesome-side-project`, lists of "buy/sell business" tools.
      - PR line format: `- [Startup Market](https://startupmarket.tech) — marketplace of startups for sale with revenue read live from Stripe/LemonSqueezy/Polar.`
- [ ] (Optional, strong) Publish a small **public repo** under the project's GitHub — e.g. a
      short "State of verified-MRR startups for sale" data snapshot (CSV/README) generated from
      the catalog. A citable, updatable data artifact AI loves. Ask Claude to build it.
